# Project History

The repository consolidates work previously developed in staged engineering increments:

1. Sprint 0 — repository/infrastructure foundation.
2. Sprint 1 — identity, scoped RBAC, MFA and organization structure.
3. Sprint 2 — framework engine, translations, version locking, import/export and crosswalks.
4. Sprint 3 — common controls, assets, risk methodology/evaluations, treatments and RTP.
5. Sprint 4 — assessments, compliance, reusable evidence, findings and CAPA.
6. Sprint 5 — internal audit, workpapers, control tests, document management and report factory.
7. Sprint 6 — AI gateway, local AI, permission-safe RAG, workflows, notifications and production hardening.
8. Pilot Hardening — pgvector retrieval, infrastructure connectors, golden E2E test and pilot deployment gate.

The canonical repository should preserve future history through normal commits, PRs, tags and releases rather than separate sprint ZIP files.
